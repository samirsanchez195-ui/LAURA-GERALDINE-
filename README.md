# GLOWGE · Agencia de Marketing & Contenido

Sitio web oficial, catálogo interactivo y cotizador para **GLOWGE**.
Encargada: **Laura Geraldine**

## 🚀 Características
- **Identidad de lujo accesible**: Estética limpia con paleta oscura, tonos café, bronce y dorado.
- **Portafolio & Catálogo**: Galería con filtros por categoría (Reels, Tomas de Dron, Branding, Meta Ads) y referencias puntuales.
- **Planes & Tarifas**: Detalle transparente de planes mensuales (Esencial, Crecimiento, Impulso, Presencia) y planes con Drone.
- **Cotizador Personalizado**: Calculadora en tiempo real para presupuestos a la medida.
- **Conversión Directa**: Formulario y botones enlazados directamente a WhatsApp (**+57 314 293 1148**).

## 🛠️ Tecnologías
- HTML5 / CSS3 semántico
- Tailwind CSS
- Google Fonts (Syne, Cormorant Garamond, Plus Jakarta Sans)
- FontAwesome Icons
- JavaScript nativo
